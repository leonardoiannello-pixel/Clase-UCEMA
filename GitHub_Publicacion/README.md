# Job Search Agent

Workspace for a supervised job-search workflow that can:

- evaluate vacancies against configurable search criteria;
- prepare role-specific CV and application drafts from verified facts;
- track application status without duplicating submissions;
- require human review before any application is submitted.

## Privacy

This repository contains reusable instructions, schemas, sanitized examples,
and explicitly approved anonymized CV samples in `public-cv/`. Source CVs,
contact details, compensation information, tailored documents, and real
application records are kept in ignored local folders and must not be committed.

## Workflow

1. Add or update verified candidate information locally.
2. Review and rank an opportunity.
3. Ask for missing role-specific facts.
4. Generate application materials.
5. Review the completed form and documents.
6. Submit only after explicit user approval.
