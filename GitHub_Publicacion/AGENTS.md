# Workspace instructions

## Purpose

Maintain a supervised job-search workflow that evaluates roles, prepares
truthful application materials, and tracks outcomes.

## Privacy and factual integrity

- Never commit source CVs, contact data, compensation data, credentials,
  application answers, or tailored deliverables. Only the two explicitly
  approved anonymized samples in `public-cv/` may be public.
- Treat `work/`, `outputs/`, and `private/` as confidential local directories.
- Never invent employment history, dates, education, languages, tools,
  responsibilities, achievements, or metrics.
- Ask the user to confirm ambiguous or missing facts before using them.

## External actions

- Researching and drafting may proceed without submission.
- Before submitting an application, sending a message, or uploading personal
  files, show the user a final summary and obtain explicit approval.
- Record a submission only after verifying that the portal accepted it.

## Repository scope

Commit only generic workflow instructions, schemas, templates, and sanitized
examples. Keep personal source material outside version control.
